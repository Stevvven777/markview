# Integrate Markview Web components

These guides are for applications consuming the Web/TypeScript packages.
The native Markview application remains read-only; `@markview/editor` supplies
editing in a host application.

- [Component guide](mvaac.md): packages, quick start, editing, fonts, stylesheets, transport, deployment, lifecycle and migration.
- [Source navigation and TOC](mvaac-source-api.md): coordinates, versions, geometry, reading positions and heading navigation.
- [Asynchronous image resources](mvaac-resources.md): requests, priorities, completion, cancellation and host ownership.
- [MVSS format](../users/stylesheets.md): shared stylesheet syntax; use the component guide for registration and selection APIs.

Building or changing this repository? Use [Web component development](../developers/web.md).
Rust implementation details belong in [developer documentation](../developers/README.md).
