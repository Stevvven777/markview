# 留一点时间，读下去

有些文字值得慢慢读。一篇札记、一章书，或是一段想要弄懂的解释：
打开文档，找到上次停下的位置，让注意力回到内容本身。

## 让想法清晰呈现

好的排版，让**重要的想法**有清楚的层次，也给*细微的表达*留一点空间。
公式自然融入所在的句子：$e^{i\pi}+1=0$。更长的推导，则可以独占一行。

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

> 让页面安静，让想法说话。

## 从阅读笔记到代码

```rust
fn reading_time(words: usize) -> usize {
    words.div_ceil(240)
}
```

表格、脚注、通往下一章的链接，都有自己的位置。
选一个舒服的主题，按自己的节奏读下去。
